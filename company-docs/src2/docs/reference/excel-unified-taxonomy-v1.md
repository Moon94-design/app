# Excel 통합 분류 SSOT v1

작성일: 2026-02-11  
목적: `kora/hometax/extra`의 흩어진 입력값을 하나의 실사용 분류 체계로 통합하고, 예외 처리/학습 규칙을 고정한다.

---

## 1) 분류 축(실사용 기준)
- 1차(필수): `매입` | `매출`
- 2차(필수): 업무 분류/재질 분류
  - 매입: `PP`, `PE`, `운송료`, `서비스`
  - 매출: `PP`, `PE` (가공품 기준)
- 3차(권장): 품목 상태/제품 형태
  - 매입(PP/PE): `스크랩(비압축)` | `압축품`
  - 매출(PP/PE): `분쇄품` | `미세척분쇄품` | `압출펠렛`
  - 운송료/서비스: 필요 시 세부 타입 추가

메모:
- UI 표시는 실사용 명칭(`원재료매입`, `운송료`, `서비스`, `가공품매출`)을 사용하되, 저장 구조는 1/2/3차로 분리한다.
- 3차부터는 단가 침범 가능성이 있어, 자동보다 반자동/수동 우선 정책을 적용한다.

---

## 1.5) 필수 분류 단계
- 모든 항목은 최소 `1차 + 2차`를 필수로 가진다.
- `3차`까지 완료되면 기본 통과로 본다(운영 확정 최소선).
- 4차/5차는 선택 확장(현장 세부 분류 필요 시).
- 분류 미완료 항목은 저장하더라도 `reviewQueue`에서 제거하지 않는다.

---

## 2) 매입/매출 분리 원칙
- 같은 `PP/PE` 텍스트라도 1차(`매입/매출`)가 다르면 별개로 분류한다.
- 매입:
  - 가공 전 원재료(스크랩/압축품) -> `원재료매입`
- 매출:
  - 가공 후 제품(분쇄품/미세척분쇄품/압출펠렛) -> `가공품매출`

---

## 3) 원재료 분류 트리(고정)
### 3.1 스크랩(비압축)
- 정의: 비압축 원재료
- 1차: `PP` | `PE`
- 2차(기준 태그):
  - PP 예: `일반`, `단프라`, `파렛트`
  - PE 예: `상자`, `말통`, `파렛트`, `일반`
- 3차: 세부 하위종(파렛트 종류/상자 종류 등)
- 사용자 태그: 기준 태그 외 자유 입력 허용

### 3.2 압축품
- 정의: 압축된 원재료
- 1차: `PP` | `PE`
- 2차(기준 태그): 압축품은 최소 태그 중심으로 운영
  - 예: `말통`, `일반`
- 사용자 태그: 필요 시 추가 입력 허용

---

## 4) 사이트(site) 처리 정책
- 분류 사전은 `공통 1개`로 운영한다.
- `대구/성주`는 분류키가 아니라 `site 태그`로만 저장한다.
- 조회/집계 시 site 태그로 구분한다.

---

## 5) 통합 라벨링 규칙
- 같은 표현을 묶어 공통 라벨로 저장한다.
- 예시:
  - `운송비/운임/운반비/운송료` -> `운송료`
  - `PP 압축품/PP압축/PP(압축)` -> `원재료매입 > 압축품 > PP`
  - `PE 압축품/PE압축/PE(압축)` -> `원재료매입 > 압축품 > PE`
- 실제 라벨명은 운영자가 합의한 단어로 고정하고, 원문은 별도 보존한다.

---

## 6) 자동 분류 + 예외 분류 워크플로우
### 6.1 자동 분류
- 사전 규칙으로 분류 가능한 항목은 자동 분류한다.
- 자동 분류 결과:
  - `categoryAuto`
  - `ruleSource`(기본 규칙/학습 규칙)

### 6.2 예외 큐(reviewQueue)
- 자동 분류 실패/애매 항목은 예외 큐에 표시한다.
- UI 동작:
  1. 카테고리 버튼 선택
  2. 예외 항목 다중 선택
  3. 선택 항목을 해당 카테고리로 일괄 분류
  4. 분류된 항목은 예외 목록에서 제거

### 6.2.1 단가 범위 기반 일괄 분류(반자동)
- 사용자가 `단가 범위(min~max)`를 직접 입력해 예외 항목을 일괄 분류할 수 있다.
- 적용 예:
  - 특정 단가 구간 -> `원재료매입 > 압축품 > PP`
  - 다른 구간 -> `원재료매입 > 스크랩 > PE`
- `3차`도 동일하게 단가 범위 조건으로 일괄 적용 가능(선택)
- 단가 범위에 속하지 않는 항목은 예외 목록에 계속 남긴다.
- 주의:
  - 긴 날짜 구간에서는 단가 변동으로 다른 품목이 침범할 수 있음
  - 따라서 권장 조건은 `매입/매출 구분 + 날짜 범위 + 단가 범위` 조합
  - 모든 일괄수정은 `날짜 범위`를 필수 조건으로 가진다(날짜 없는 단가 일괄 금지)
  - 엑셀 업로드 직후 일괄수정에도 동일 규칙을 적용한다

### 6.3 이전 분류 재사용
- 같은 예외 원문이 다시 나오면 이전 분류를 제안한다.
- 문구: `이전의 분류대로 포함 하겠습니까?`
- 사용자 확인 후 반영:
  - 1회 확인: 추천 상태 유지
  - 2회 이상 동일 확인: 자동 분류 후보로 승격
- 단, `같은 비고 원문`이라도 `거래처/품목/단가/날짜 구간 맥락`이 다르면 자동확정 금지
- 재사용 규칙은 항상 `확인 버튼`을 거치는 반자동으로 동작

### 6.6 3차 자동/반자동 우선순위
- 3차는 아래 우선순위로 채운다:
  1. 원문(비고/품목명)에 3차 명시 키워드가 있으면 자동 분류
  2. 명시 키워드가 없으면 날짜+단가 범위 규칙으로 반자동 제안
  3. 그래도 미분류면 수동 분류
- 3차까지만 완료되면 통과 처리하고, 4차/5차는 필요 시 나중에 일괄 보강 가능

### 6.7 세금계산서-계량현황 매칭 규칙(초안)
- 목적: 매입/매출 세금계산서와 계량현황 레코드를 거래 단위로 연결
- 1차 매칭(자동 후보):
  - `site + 거래일자 + 총금액` 일치
- 2차 매칭(검토 후보):
  - `site + 거래일자 유사 + 금액 근소 차이` (자동 확정 금지)
- 매칭 실패:
  - 각 레코드는 독립 거래로 유지
  - `unmatched` 표시를 남겨 후속 검토 대상에 포함
- 주의:
  - 세금계산서는 지연 발행이 가능하므로, 장기간 후행 매칭은 검토 큐에서 확인한다.

### 6.4 자동 규칙 등급 분리
- 기본 규칙(초기 사전)과 학습 규칙(사용자 확정 누적)은 분리 저장한다.
- 이유: 착오 분류를 나중에 별도로 검토/수정하기 위해

### 6.5 수동 분류 입력 + 자동완성 추천
- 기존 카테고리에 포함되지 않는 예외는 사용자가 `1차/2차/3차`를 직접 입력할 수 있다.
- 수동 입력값은 분류 기록에 저장한다.
- 이후 같은/유사 예외를 분류할 때, 과거 수동 입력값을 자동완성 추천으로 노출한다.
- 추천은 자동 적용하지 않고 항상 사용자 확인 후 확정한다.

## 7) 저장 필드(권장)
- `categoryAuto`
- `categoryFinal`
- `categoryPath` (예: `원재료매입>스크랩>PP>일반`)
- `site`
- `ruleSource` (`base` | `learned`)
- `ruleVersion`
- `isLearnedRule`
- `reviewState` (`auto` | `suggested` | `confirmed`)
- `classificationLevel` (필수 완료 단계: 1/2/3)
- `priceBandRuleId` (단가 범위 일괄분류 규칙 식별자)
- `manualInputHistoryRef` (수동 분류 자동완성 참조)
- `level1` (`매입` | `매출`)
- `level2` (예: `PP` | `PE` | `운송료` | `서비스`)
- `level3` (예: `스크랩` | `압축품` | `분쇄품` | `미세척분쇄품` | `압출펠렛`)
- `dateRangeFrom`, `dateRangeTo` (일괄수정 조건)
- `matchState` (`matched` | `candidate` | `unmatched`)
- `matchedDocRef` (세금계산서/계량현황 연결 참조)

---

## 8) 운영 점검 포인트
- 학습 규칙으로 승격된 항목은 별도 목록에서 주기적으로 재검토한다.
- 기준 태그가 늘어날 때 기존 항목 재분류 영향도를 점검한다.
- 소스별(`kora/hometax/extra`) 원문은 항상 보존해 역추적 가능하게 유지한다.
- 재사용 추천/학습 규칙은 완전 자동확정이 아니라 반자동 확인 흐름으로 유지한다.

---

## 9) 분류 규격화 시점(언제 고정하는지)
- 1단계(지금): 문서 SSOT 고정
  - 1/2/3차 분류 기준, 용어, 예외 처리, 일괄수정 조건 확정
- 2단계(엑셀 이관 직후): 업로드 후 검토 화면에서 규격 적용
  - 자동 분류 + 예외 큐 + 날짜+단가 일괄분류 적용
- 3단계(운영 2~4주): 학습 규칙 정리
  - 반복 확정 항목을 learned 규칙으로 승격하고 오분류 점검
- 4단계(안정화 후): 입력 문구 표준화
  - 비고/품목 자유문구를 표준 문구로 유도(선택값/자동완성 강화)

## 10) 조회/집계를 위한 필수 저장 항목
- 공통 식별:
  - `recordId`, `source`, `sourceDocId`, `sourceRowId`, `importedAt`
- 시간/위치:
  - `date`, `site`
- 거래 핵심:
  - `amountTotal`, `unitPrice`, `qty`
- 거래 주체:
  - `counterpartyName`, `counterpartyBizNo`, `counterpartyId(매핑 시)`
- 업무 키:
  - `vehicleNo`, `partnerCode`, `itemNameRaw`
- 분류 결과:
  - `level1`, `level2`, `level3`, `categoryFinal`, `reviewState`
- 매칭 추적:
  - `matchState`, `matchedDocRef`
- 원문 보존:
  - `remarkRaw`, `itemRaw`, `normalizedText`

메모:
- 차량번호/거래처/품목/날짜는 조회 필터 핵심이므로 누락 시 예외로 유지한다.
