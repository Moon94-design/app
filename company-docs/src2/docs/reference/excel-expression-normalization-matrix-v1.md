# Excel 표현 형식 통합 매트릭스 v1

작성일: 2026-02-11  
목적: 소스별(`KORA/Hometax/Extra`) 표현 차이를 `X형식: A,B,C` 형태로 통합 정의하고, 예외 문구를 분리 관리한다.

---

## 소스 표기(색상)
- 🟢 `A` = KORA
- 🔵 `B` = Hometax
- 🔴 `C` = Extra

---

## 1) 날짜(`date`) 형식
X형식: `YYYY-MM-DD`

- `YYYY-MM-DD` 형식: 🔵B
- `YYYYMMDD` 형식: 🔵B
- `M/D/YY` 형식: 🟢A, 🔴C
- `OTHER` 형식: 🔴C

정규화 목표:
- 최종 저장은 모두 `YYYY-MM-DD`
- `M/D/YY`, `YYYYMMDD`, `OTHER`는 파서에서 변환
- 변환 실패는 `dateParseError` 예외 큐로 이동

---

## 2) 금액(`amount`) 형식
X형식: `decimal-number` (저장 시 숫자형)

- `comma-number` 형식(예: `1,234,567`): 🟢A, 🔵B, 🔴C
- `plain-number` 형식(예: `1234567`): 🟢A, 🔴C
- `OTHER` 형식: 🔵B, 🔴C

정규화 목표:
- 쉼표 제거 후 숫자형 저장
- `OTHER`는 원문 보존 + 예외 분류

---

## 3) 단가(`unitPrice`) 형식
X형식: `decimal-number` (저장 시 숫자형)

- `plain-number`: 🟢A, 🔵B, 🔴C
- `comma-number`: 🔵B, 🔴C

정규화 목표:
- 숫자형 통일
- 날짜 범위와 함께 일괄분류 조건으로 사용

---

## 4) 거래처 코드/사업자번호 형식
X형식:
- `partnerCode`: `digits-string`
- `bizNo`: `bizNoNormalized(숫자만)` + `bizNoRaw(원문)`

### 4.1 거래처 코드(`partnerCode`)
- `digits` 형식: 🟢A
- `OTHER` 형식: 🟢A

### 4.2 사업자번호(`bizNo`)
- `NNN-NN-NNNNN` 형식: 🔵B
- `10-digits` 형식: 🟢A

정규화 목표:
- 저장 시 `bizNoNormalized`(숫자만) 병행
- 출력/표시는 원문 포맷 유지 가능

---

## 5) 전표/문서 식별번호 형식
X형식:
- KORA: `site + slipNo(prefix2+digits)`
- Hometax: `site + approvalNo + itemSeq`

- `prefix2+digits` 형식(예: `CP2502110001`): 🟢A
- `OTHER` 형식(승인번호 포함): 🔵B

정규화 목표:
- KORA는 `site + slipNo`로 중복 판정
- Hometax는 `site + 승인번호 + 품목순번` 조합

---

## 6) 텍스트 문구 분류(비고/품목명)
X형식:
- `level1`: 매입/매출
- `level2`: PP/PE/운송료/서비스
- `level3`: 스크랩/압축품/분쇄품/미세척분쇄품/압출펠렛

### 6.1 분류된 문구(현재 규칙에서 인식)
- `운송료` 카테고리: 🟢A, 🔵B
  - 예: `운송비`, `운임`, `운송료(...)`, `...하차`
- `PP` 카테고리: 🟢A, 🔵B
  - 예: `PP압축품`, `PP(압축)`, `r-PP`, `플라스틱 : PP`
- `PE` 카테고리: 🟢A, 🔵B
  - 예: `PE압축품`, `PE(압축품)`, `PE세척품(...)`, `플라스틱 : PE`

### 6.2 분류 불가(예외) 문구
- 현재 분류 불가 고유 문구: `95개`
- 대표 예시:
  - 🔵B: `망간봉 外`, `L.P.G외 고압가스`, `폐합성수지`, `볼트대금`, `전기요금(...)`
  - 🟢A: `상자`, `말통`, `고철`, `파레트혼입`, `수액백`, `금속캔 : 금속캔`

운영 규칙:
- 분류 불가 문구는 `reviewQueue` 유지
- 날짜+단가 범위 일괄분류 또는 수동분류로 처리
- 수동 확정 기록은 learned rule 후보로 누적

### 6.3 분류 불가 -> 규격화 후보 묶음(1차)
X형식: `예외원문 -> (후보 level2/level3 + 보조태그)`  
원칙: 자동확정 금지, 반자동 제안 후 사용자 확인

#### 전 품목 공통 분기 원칙(중요)
- `매입/매출 품목 전체`에 동일 적용:
  1. 1차(`매입/매출`) 먼저 확정
  2. 2차(`PP/PE/운송료/서비스`) 확정
  3. 3차는 단어 단독 확정 금지(다의어 가능)
  4. `날짜범위 + 단가범위 + (거래처/site 선택조건)`으로 3차 후보 제안
  5. 사용자 확인 후 `categoryFinal` 확정
- 즉, `말통`만이 아니라 `파렛트/상자/혼합/압축/분쇄` 등 품목 전반을 같은 방식으로 처리한다.

#### 그룹 A) PE 스크랩(용기형)
- 후보: `level2=PE`, `level3=스크랩` (기본)
- 보조태그: `container:말통|상자`
- 묶음 예시:
  - `말통`, `큰말통`, `PE말통`, `PE세척품(말통)`
  - `상자`

조건부 분기(중요):
- `말통`은 단어만으로 3차 자동확정 금지
- 분기 우선순위:
  1. `level1=매출`이면 `level3=분쇄품` 후보 우선
  2. `level1=매입`이면 `level3=스크랩/압축품`을 `날짜+단가 범위`로 결정
  3. 범위 미일치 시 예외 큐 유지 후 수동 확정

#### 그룹 B) 파렛트 혼입
- 후보: `level2=PP/PE`, `level3=스크랩`
- 보조태그: `mix:pallet`
- 묶음 예시:
  - `파레트혼입`, `파레트`, `파렛트대여반납`, `나무파레트 130kg`

#### 그룹 C) 유틸리티/공공요금
- 후보: `level2=서비스`, `level3=유틸리티`
- 보조태그: `utility`
- 묶음 예시:
  - `전기요금(...)`, `가스사용료`, `폐수`, `폐수처리비`, `일반폐수`

#### 그룹 D) 정산/계좌 참조 메모
- 후보: 분류 미부여(참조정보)
- 보조태그: `finance_memo`
- 묶음 예시:
  - 은행명/계좌번호/전화번호/숫자 단독/기간 문자열
  - 예: `농협...`, `신한은행...`, `053...`, `26.1.1~1.31`

#### 그룹 E) 비플라스틱 품목
- 후보: `nonPlasticType` 보조분류
- 보조태그: `non_plastic:metal|paper|medical`
- 묶음 예시:
  - `고철`, `철캔`, `금속캔 : 금속캔`, `종이팩`, `수액백`

#### 그룹 F) 작업/보정 메모
- 후보: 분류 미부여(운영 메모)
- 보조태그: `ops_note`
- 묶음 예시:
  - `에러`, `...오차 ... 감량...`, `2차계근 ... 잘못 클릭됨`

#### 그룹 G) 원재료 기타
- 후보: `level2` 미확정, `reviewQueue` 유지
- 보조태그: `material_candidate`
- 묶음 예시:
  - `폐합성수지`, `망간봉 外`, `볼트대금`, `톤백`

운영 규칙:
- 위 그룹은 “자동확정”이 아니라 “규격화 후보”다.
- 같은 원문이라도 날짜/거래처/단가 맥락이 다르면 다른 분류가 가능하므로 최종 확인이 필요하다.
- 동일 원문 다의어(예: `말통`, `혼합`, `파레트`)는 `level1 + 날짜범위 + 단가범위` 3조건이 맞아야 자동 후보로 제안한다.
- 품목 전체 원칙:
  - 매입 품목도 `스크랩/압축품`을 단어만으로 확정하지 않는다.
  - 매출 품목도 `분쇄품/미세척분쇄품/압출펠렛`을 단어만으로 확정하지 않는다.
  - 3차 확정은 항상 반자동 검토를 거친다.

---

## 7) 우선 적용 규격화 규칙
1. 날짜/금액/단가 숫자형 정규화(파서 레벨)  
2. 비고+품목명 결합 텍스트로 1차 자동 분류  
3. 분류 불가 문구는 예외 큐로 유지  
4. 수동/일괄 분류 결과를 learned 규칙으로 누적(자동확정 금지, 반자동 확인)
