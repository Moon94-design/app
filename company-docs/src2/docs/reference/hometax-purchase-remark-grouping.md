## 5) 원문 -> 통합카테고리 매핑 초안 (검토용)
- `운송비`, `운임`, `운송료(...)`, `...→대구`, `...-대구` -> `운송비(통합)`
- `...수수료`, `...정기청소`, `...렌탈료`, `...임대료`, `...수리...`, `...대행...` -> `서비스비`
- `전기요금(...)`, `가스사용료`, `L.P.G...` -> `유틸리티/요금`
- `PE/PP/톤백/부품/폐.../소모품류` -> `재료/소모품`
- `계좌/전화/기간/차량번호/숫자 단독` -> `참조메모(분류보조)`

---

## 6) 적용 제안
1. 분류 엔진은 `비고`만 보지 말고 `품목명 + 비고` 결합 텍스트로 판정  
2. 최종 분류값은 아래 두 단계로 저장  
   - `categoryAuto` (자동 분류 결과)  
   - `categoryFinal` (사용자 확정값)  
3. `참조메모`는 분류보조 필드로만 보관하고, 자동 확정 근거로 사용하지 않기
