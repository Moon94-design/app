- 요청대로 `확실 / 비확실 / 추정`을 분리하고, 가능한 많은 정량 정보를 포함했다.

다음 질문: 이 분석 문서를 기준으로, 바로 `분류 룰 JSON 초안(v1)`까지 생성할까?

## 핵심 로직 3줄
- 1) 엑셀 파일 전체를 소스별로 분리 집계해 정량 근거를 먼저 확보했다.
- 2) 판단 문구를 `확실/비확실/추정`으로 구분해 의사결정 리스크를 분리했다.
- 3) 결과를 운영 실행 항목(site 필수, duplicateQueue, exceptionQueue, 반자동 분류)으로 연결했다.

## 입문자 설명 3줄
- 1) 데이터 분석은 먼저 “무슨 파일이 몇 개 있는지”부터 확인해야 한다.
- 2) 숫자로 확인된 사실과 추측을 섞지 않으면 나중에 실수가 줄어든다.
- 3) 최종 목적은 문서가 아니라, 실제 시스템 규칙으로 옮길 수 있는 기준을 만드는 것이다.

## 주의 사항
- AI가 통계를 빨리 내는 과정에서 컬럼 의미(예: 금액/부가세합 정의)를 과해석할 수 있다.
- 샘플 기간이 제한되어 있어 계절/장기 패턴은 왜곡될 수 있다.

## 향후 과정
- 다음 작업에서 이 분석 문서의 수치/용어를 `rule dictionary JSON`의 seed 데이터로 고정해야 한다.
- KORA/Hometax/Extra 파서가 동일 엔티티 키를 쓰도록 연결하지 않으면, 문서 분석과 실제 데이터 흐름이 다시 분리될 수 있다.
