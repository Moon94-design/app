# 테마 토글 추가 (다크/라이트/오션)

> 작성일: 2026-02-12
> 주제: 기존 다크 유지 + 라이트 + 커스텀 오션 테마를 버튼으로 전환

---

## 변경 요약
- 상단 헤더에 테마 전환 버튼(`테마: 다크/라이트/오션`)을 추가했다.
- 테마 모드를 저장해 새로고침 후에도 마지막 선택이 유지되도록 했다.
- `shell.css`를 CSS 변수 중심으로 정리해 테마별 색상 토큰을 분리했다.

## 코드 변경
- `company-docs/src2/app/shell/Shell.tsx`
  - 테마 상태/순환 버튼/저장 로직 추가
  - `document.documentElement[data-theme]` + `colorScheme` 동기화
- `company-docs/src2/app/shell/shell.css`
  - 공통 토큰 정리
  - `:root[data-theme="light"]`, `:root[data-theme="ocean"]` 추가
  - 버튼/입력/탭/카드/헤더 색상을 변수 기반으로 전환
- `company-docs/src2/kernel/repo/keys.ts`
  - `uiThemeMode` 저장 키 추가

## 게이트
- `npm.cmd run build` 성공

## 핵심 로직 3줄
- 1) 테마 상태를 `dark -> light -> ocean` 순환으로 변경하고 UI 버튼으로 노출했다.
- 2) 선택된 테마를 저장소에 기록하고 앱 시작 시 다시 읽어 복원한다.
- 3) 루트 엘리먼트의 `data-theme` 값을 기준으로 CSS 변수를 갈아끼워 전체 색상을 변경한다.

## 입문자 설명 3줄
- 1) 버튼을 누를 때마다 앱의 색상 모드가 하나씩 바뀐다.
- 2) 마지막으로 고른 모드는 저장해두기 때문에 새로고침해도 유지된다.
- 3) 화면 색은 여러 군데를 직접 바꾸는 게 아니라, 공통 변수만 바꿔서 한 번에 바뀌게 만들었다.

## 주의 사항
- 패턴 반복으로 다크 전용 하드코딩 색상이 일부 파일에 남아 있을 수 있다(특히 page별 개별 CSS).
- 테마 확장 시 변수 추가만 하고 실제 사용 위치 치환을 놓치면 특정 컴포넌트만 색이 튈 수 있다.

## 향후 과정
- `manage-page-layout.css` 등 개별 페이지 CSS도 토큰 기반으로 점진 정리하면 테마 일관성이 올라간다.
- 서버 이관 단계에서도 테마 저장 키(`uiThemeMode`)는 클라이언트 선호 설정으로 분리 유지하면 충돌을 줄일 수 있다.
