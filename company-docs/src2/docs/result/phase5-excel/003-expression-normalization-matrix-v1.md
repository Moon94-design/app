# 표현 문구 통합 매트릭스 v1 작성

> 작성일: 2026-02-11
> 주제: 소스별 표현 차이를 `X형식: A,B,C`로 통합 정리 + 예외 문구 분리

---

## 변경 요약
- 네가 요청한 형태로 항목별 표현 차이를 정리했다.
- 소스 표기를 색상 기준으로 고정했다.
  - 🟢A(KORA), 🔵B(Hometax), 🔴C(Extra)
- 분류 불가 문구를 예외 목록으로 분리했다.

## 추가 문서
- `company-docs/src2/docs/reference/excel-expression-normalization-matrix-v1.md`
  - 날짜/금액/단가/식별번호 형식 차이
  - 비고/품목명 분류 가능 문구
  - 분류 불가 예외 문구 처리 규칙

## 게이트
- 문서 작업만 수행(빌드 미실행)

다음 질문: 이 매트릭스 기준으로 parser에서 바로 적용할 정규화 함수 목록(date/number/text)을 코드화할까?

## 핵심 로직 3줄
- 1) 소스별 형식 차이를 `X형식: A,B,C`로 명시해 파서 규칙 기준을 고정했다.
- 2) 텍스트 문구는 분류 가능/불가를 분리해 예외 큐 흐름을 명확히 했다.
- 3) 분류 불가 문구는 자동확정하지 않고 반자동 검토 대상으로 유지하게 했다.

## 입문자 설명 3줄
- 1) 같은 데이터라도 파일마다 표현이 달라서 먼저 형식표를 만드는 게 중요하다.
- 2) 형식표가 있으면 코드에서 어떤 값을 어떻게 바꿀지 바로 구현할 수 있다.
- 3) 분류 안 되는 문구를 따로 모아두면 나중에 규칙을 개선하기 쉬워진다.

## 주의 사항
- AI가 자동 분류 키워드를 넓게 잡으면 서로 다른 의미를 같은 카테고리로 묶을 수 있다.
- 이번 매트릭스는 현재 샘플 기준이라, 신규 파일 유입 시 예외 목록이 늘어날 수 있다.

## 향후 과정
- 다음 단계에서 매트릭스 규칙을 parser 정규화 함수로 옮겨 문서-코드 일치를 만든다.
- 예외 문구를 주기적으로 재검토해 learned rules에 반영하고, 오분류는 즉시 롤백 가능하게 관리한다.

## 후속 반영(요청사항)
- 각 항목 섹션 맨 위에 `X형식`(최종 통합/저장 형식) 라인을 추가했다.
- 적용 파일:
  - `company-docs/src2/docs/reference/excel-expression-normalization-matrix-v1.md`

## 반영 내용 요약
- 날짜: `X형식 = YYYY-MM-DD`
- 금액/단가: `X형식 = decimal-number(숫자형 저장)`
- 거래처코드/사업자번호: `X형식`을 정규화+원문 병행으로 명시
- 전표/문서 식별번호: 소스별 통합키 `X형식` 명시
- 텍스트 분류: `level1/2/3` 기준 `X형식` 명시

## 후속 반영(분류 불가 규격화)
- `분류 불가`를 그대로 두지 않고 규격화 후보 묶음을 추가했다.
- 핵심 반영:
  - `말통/상자` -> `PE 스크랩` 후보
  - `파레트혼입` -> `혼합 스크랩 + pallet 태그` 후보
  - 계좌/은행/숫자 문자열 -> `정산 참조 메모` 그룹
  - 고철/종이팩/수액백 -> `비플라스틱` 그룹
- 정책:
  - 위 묶음은 자동확정이 아니라 반자동 제안 후 확인

## 후속 반영(다의어/단가 분기 강화)
- 요청사항 반영:
  - `말통`은 단독 키워드로 3차 확정하지 않음
  - 매출 문맥의 `말통`은 `분쇄품` 후보
  - 매입 문맥의 `말통`은 `스크랩/압축품`을 날짜+단가 범위로 분기
- 일반화:
  - `상자`, `파레트/파렛트`, `혼합`도 다의어로 처리
  - 위 다의어는 `level1 + 날짜범위 + 단가범위`가 맞을 때만 자동 후보 제안
  - 아니면 예외 큐 유지 후 수동 확정

## 후속 반영(전 품목 공통 규칙 확장)
- 요청사항 반영:
  - 말통/파렛트뿐 아니라 매입·매출 품목 전체를 동일 로직으로 처리
- 정책 변경:
  - baseRules는 원칙적으로 `level2`까지만 확정
  - `level3`는 전 품목 공통으로 `date+priceBand` 또는 수동 확정으로만 결정
  - 품목 단어는 3차 확정값이 아니라 후보 신호로만 사용
