# Excel 하이브리드 B단계 체크리스트 작성

> 작성일: 2026-02-11
> 주제: `/excel` native 이관 완료를 위한 전용 작업순서표 신규 작성

---

## 변경 요약
- 기존 체크리스트를 참조해, 하이브리드 전략 B단계 전용 체크리스트를 새로 만들었다.
- 요청대로 guide 흐름(`DOCS_GUIDE -> main_rule -> STATUS -> GATES`)을 시작 체크에 명시했다.

## 추가 문서
- `company-docs/src2/docs/roadmap/phase5/work-order-excel-hybrid-phase-b.md`
  - 시작 체크(guide 참조)
  - 범위 고정/금지 항목
  - 타입/파서/UI/저장 파일 단위 체크
  - 게이트 및 완료 후 문서 반영

## 설계 판단
- 이번 체크리스트는 “규칙 고도화”보다 “이관 완료(B단계)”를 먼저 닫도록 구성했다.
- reason:
  - 현재 SHADOW 상태를 빨리 MIGRATED 조건으로 끌어올려야 후속 C/D 단계가 안정적으로 진행됨.

## 게이트
- 문서 변경만 수행(빌드 미실행)

다음 질문: 이 체크리스트 기준으로 바로 B단계 코드 작업(legacy parser/panel 제거) 들어갈까?

## 핵심 로직 3줄
- 1) Guide 기반 시작 체크를 강제해 매 작업 시작 품질을 일정하게 만들었다.
- 2) `/excel` @legacy 제거를 파일 단위로 쪼개 실행 가능하게 만들었다.
- 3) B단계 완료 조건을 게이트 중심으로 고정해 상태 판정을 명확히 했다.

## 입문자 설명 3줄
- 1) 큰 작업도 체크리스트로 쪼개면 놓치는 부분이 줄어든다.
- 2) 먼저 기준 문서를 확인하면 중간에 방향이 틀어질 가능성이 줄어든다.
- 3) 완료 조건을 숫자/테스트로 정하면 “대충 완료”를 막을 수 있다.

## 주의 사항
- AI가 체크리스트를 만들 때 실제 코드 복잡도를 과소평가할 수 있다.
- legacy 제거 중 타입만 바꾸고 저장 흐름 검증을 빼먹을 위험이 있다.

## 향후 과정
- 다음 단계에서 이 체크리스트를 그대로 따라 B단계 코드 변경을 진행한다.
- 완료 후 `rg @legacy` 재검증과 수동 업로드 3종 시나리오를 반드시 통과시킨다.
