# 흰 화면 수정

> 작성일: 2026-02-09
> 주제: lazy(loader) 렌더 내부 호출로 인한 흰 화면 수정

---

## 결론
- 흰 화면 원인은 routes.tsx에서 lazy(loader)를 렌더 경로(map 내부)에서 매번 생성한 것
- 해결: lazy 컴포넌트 생성은 모듈 스코프에서 1회만 수행

## 왜 이전 결론이 틀렸는지 (분석)
- 런타임 버그(흰 화면)와 에디터 진단(TS 빨간줄)을 같은 급으로 섞어 우선순위를 잘못 잡음
- 빌드가 통과하는 상황에서 TS 빨간줄을 런타임 원인처럼 취급해 불필요한 수정 방향(.tsx 확장자 추가)을 제안함
- 결과적으로 "흰 화면"의 직접 원인을 먼저 제거하지 못했고, 문제 분리를 실패함

## 변경 사항
- routes.tsx: lazy(loader) 생성 위치를 모듈 스코프로 이동

## 확인
- 흰 화면 해소 확인 (dev)
- 빌드 결과 확인: npm run build

## 비고
- main.tsx import 확장자 변경은 하지 않음 (현재 단계에서는 리스크 회피)
