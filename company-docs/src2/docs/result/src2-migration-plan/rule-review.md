## 1. "이 정도면 돌발 행동을 막을 수 있는가?"

**거의 가능하다.** main_rule.md는 다음을 모두 갖추고 있음:

| 요소 | 포함 여부 |
|------|-----------|
| 하드 룰 (절대 금지) | ✅ R1~R7 |
| 폴더 구조도 | ✅ 전체 골격 |
| alias 정의 | ✅ @kernel/@app2/@legacy |
| 게이트 (검증 조건) | ✅ G0, G1 |
| 실행 순서 | ✅ 0~4단계 |
| 페이지 이관 DoD | ✅ 5항목 |
| Repo/Draft 계약 | ✅ 인터페이스 포함 |

이 구성이면 코파일럿이 가장 자주 하는 실수(legacy import 오염, localStorage 직접 접근, impl 직접 사용, 키 하드코딩)를 모두 명시적으로 차단할 수 있음.

## 2. 참조 빈도 가이드

코파일럿에게는 **영구 기억이 없다.** 대화가 길어지면 초반 컨텍스트가 밀려남.

| 상황 | 참조 | 예시 문구 |
|------|------|-----------|
| 새 대화 시작 | **필수** | "src2/docs/rule/main_rule.md 참조. 0단계 작업 시작해." |
| 같은 대화에서 단계 전환 | **권장** | "main_rule.md 다시 확인하고 1단계 시작." |
| 같은 단계 안 연속 작업 | 생략 가능 | — |
| 결과가 이상하거나 규칙 위반 시 | **필수** | "main_rule.md 다시 읽고 R4 위반 확인해." |
| 대화가 20턴 이상 길어졌을 때 | **권장** | "main_rule.md 다시 참조해." |

**핵심**: 매 대화 첫 메시지에 한 줄만 추가하면 충분함.
