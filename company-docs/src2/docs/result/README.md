# Result 문서 분류 인덱스

작성일: 2026-02-11  
목적: `phase5` 결과 문서가 과도하게 커져 탐색이 어려운 문제를 줄이기 위해 분류 기준을 고정한다.

---

## 1) 기본 원칙
- 기존 파일은 경로 안정성을 위해 즉시 이동하지 않는다.
- 신규 결과 문서부터 하위 토픽 폴더를 사용한다.
- 필요 시 묶음 단위로 단계적 이동(링크 검증 후)한다.

---

## 2) 권장 토픽 폴더
- `phase5-excel`: 엑셀 이관/분류/매핑/사전/검증
- `phase5-ui`: 메뉴/레이아웃/스타일 통일
- `phase5-manage`: 관리 페이지 이관/리팩터
- `phase5-register`: 등록 페이지 이관/리팩터
- `phase5-core`: 공통 규칙/가드레일/기반 정책
- `phase5-SSOT`: SSOT 공장 관련 문서(기존 운영 유지)

---

## 3) 기존 phase5 파일 분류 가이드(참조)
- `034`~`051`은 대부분 `phase5-excel` 성격
- `028`~`029`는 `phase5-ui` 성격
- `020`~`027`, `030`~`033`은 `phase5-manage/register` 성격
- `001`~`012`는 `phase5-core` 성격

---

## 4) 운영 규칙
- 다음 작업부터는 성격에 맞는 하위 폴더에 결과를 기록한다.
- 번호는 폴더 단위로 독립 증가를 허용한다.
  - 예: `phase5-excel/001-...`, `phase5-ui/001-...`
