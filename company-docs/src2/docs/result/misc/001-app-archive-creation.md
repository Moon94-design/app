## 작업 내용

사용자 요청으로 현재 앱의 파일들을 압축 파일로 생성했습니다. 다른 곳에 공유하여 진행 상황을 보여주기 위한 목적입니다.

### 요구사항
- 모든 앱 파일 포함
- 문서 파일 포함
- Excel 파일 (.xls, .xlsx, .xlsm, .xlsb) 제외
- .git, node_modules, dist 등 불필요한 폴더 제외

### 생성된 파일
- 파일명: `app_archive_20260214_152635.tar.gz`
- 위치: `/home/runner/work/app/app/`
- 크기: 16MB
- 포함 파일 수: 991개

### 제외된 항목
- Excel 파일: *.xls, *.xlsx, *.xlsm, *.xlsb
- Git 저장소: .git
- 의존성: node_modules
- 빌드 결과물: dist

### 검증 결과
✅ Excel 파일이 압축 파일에 포함되지 않음 (검증 완료)
✅ 문서 파일(*.md, *.txt)이 정상적으로 포함됨
✅ 소스 코드 및 설정 파일 포함됨

---

## 핵심 로직 3줄
- 1) `tar` 명령어로 압축 파일 생성, `--exclude` 옵션으로 Excel 파일 제외
- 2) .git, node_modules, dist 등 불필요한 폴더도 제외하여 파일 크기 최적화
- 3) 타임스탬프를 파일명에 포함하여 여러 버전 관리 가능

## 입문자 설명 3줄
- 1) tar.gz는 파일들을 하나로 묶어서 압축하는 포맷으로, Linux/Unix에서 표준으로 사용됩니다
- 2) --exclude 옵션으로 특정 패턴의 파일을 제외할 수 있어, Excel 파일들을 제외했습니다
- 3) 생성된 압축 파일은 16MB로, 991개의 파일이 포함되어 있습니다

## 주의 사항
- tar 실행 중 "file changed as we read it" 경고가 발생할 수 있으나, 압축 파일 자체가 생성되면서 발생하는 정상적인 메시지입니다
- 압축 파일을 다른 곳에 공유할 때는 민감한 정보(.env, 키 파일 등)가 포함되어 있지 않은지 확인이 필요합니다
- Excel 파일이 필요한 경우 별도로 공유하거나 필터 옵션을 조정해야 합니다

## 향후 과정
- 압축 파일을 필요한 곳에 공유
- 추가로 압축 파일이 필요한 경우 타임스탬프를 업데이트하여 새 파일 생성 가능
- 특정 폴더만 압축하거나 다른 제외 조건이 필요한 경우 tar 명령어 옵션 조정
