## 핵심 로직 3줄
- 1) 분류는 최소 1차/2차가 필수이며 미완료 항목은 예외 큐에서 유지한다.
- 2) 사용자가 단가 범위를 지정해 예외 항목을 일괄 분류할 수 있게 한다.
- 3) 같은 비고 재사용은 자동확정하지 않고 항상 사용자 확인 후 반영한다.

## 입문자 설명 3줄
- 1) 큰 분류와 중간 분류를 먼저 채워야 데이터가 나중에 찾기 쉬워진다.
- 2) 항목이 너무 많을 때는 단가 범위를 이용해 한 번에 묶어 처리할 수 있다.
- 3) 자동 추천은 편의를 주되, 마지막 확인은 사람이 해야 실수를 줄일 수 있다.

## 주의 사항
- AI가 단가 범위를 강하게 추천하면서 품목 문맥(기간/거래처)을 놓치면 오분류가 생길 수 있다.
- 수동 입력 자동완성은 편하지만, 잘못된 과거 분류가 추천으로 반복될 위험이 있다.

- 반자동 확인 UI를 구현할 때 “이전 분류 적용”을 기본 체크로 두지 말고 명시 확인 흐름으로 고정해야 한다.
