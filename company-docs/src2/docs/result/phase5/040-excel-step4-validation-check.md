# 엑셀 4단계 검증 점검 (자동 가능 항목 우선)

> 작성일: 2026-02-10
> 주제: `/excel` 저장 경로 정리 단계에서 자동 검증과 수동 검증 잔여 항목 분리

---

## 점검 요약
- 자동 검증 가능한 항목(build/security/경로 응답/코드 연결)을 먼저 확인했다.
- 업로드 실제 적용 확인은 브라우저 수동 입력이 필요해 별도 체크박스로 분리했다.

## 실행 결과
- `npm.cmd run check:security` -> PASS
- `/excel` 경로 응답 -> 200
- 코드 연결 점검:
  - `ExcelImportHubPage`에서 partner/weighing/vehicle 섹션 렌더 확인
  - `useExcelImportHubPage`에서 `createPartnerRepo/createWeighingRepo/createVehicleRepo` 경유 저장 핸들러 확인

## 문서 반영
- `company-docs/src2/docs/roadmap/phase5/work-order-excel-import-hub-migration.md`
  - 수동 업로드 시나리오 3종 체크 항목 추가

## 수동 검증 잔여(사용자 실행 필요)
- [ ] partner 엑셀 1회 업로드 -> 관리/조회 반영 확인
- [ ] weighing 엑셀 1회 업로드 -> 관리/조회 반영 확인
- [ ] vehicle 엑셀 1회 업로드 -> 관리/조회 반영 확인

다음 질문: 지금 바로 네가 샘플 파일 3개로 업로드 테스트하면, 나는 결과 로그를 받아서 4단계 완료 판정까지 문서에 닫아줄까?

## 핵심 로직 3줄
- 1) 자동 점검 가능한 게이트(check:security, route 200, 코드 경로 점검)를 먼저 닫았다.
- 2) 업로드 실검증은 브라우저 수동 동작이므로 별도 체크박스로 분리했다.
- 3) work-order에 수동 3시나리오를 고정해 4단계 완료 조건을 명확히 했다.

## 입문자 설명 3줄
- 1) 자동으로 확인할 수 있는 건 먼저 확인해서 문제를 빠르게 줄인다.
- 2) 파일 업로드처럼 사람이 직접 해야 하는 테스트는 체크리스트로 분리해 놓는다.
- 3) 이렇게 나누면 "무엇이 끝났고 무엇이 남았는지"가 명확해진다.

## 주의 사항
- 자동 검증이 통과해도 실제 엑셀 파일 내용에 따라 업로드 실패가 날 수 있다(포맷/컬럼 차이).
- 수동 시나리오를 생략하면 저장 경로 정리(4단계)를 완료로 올리면 안 된다.

## 향후 과정
- 수동 3시나리오 완료 후 즉시 MIGRATION_STATUS/roadmap 단계 상태를 갱신해야 한다.
- vehicle 키 단일화 작업은 수동 검증 완료 후 별도 턴에서 진행하는 것이 안전하다.
