# 엑셀 용어 통일 + 규격화 시점/필수 저장값 고정

> 작성일: 2026-02-11
> 주제: 3차 용어 변경(분쇄품/미세척분쇄품) 및 분류 규격화 타이밍/필수 필드 명문화

- 매출 3차 용어를 다음으로 통일했다.
  - `분쇄품`
  - `미세척분쇄품`
  - `압출펠렛`
- `세척분쇄품`, `세척X분쇄품` 표기를 정리했다.
- 문서에 “분류 규격화를 언제 고정하는지”와 “조회용 필수 저장값”을 추가했다.

다음 질문: 이 필수 저장 항목을 기준으로 실제 parser output 필드 맵핑 문서까지 바로 만들까?

## 핵심 로직 3줄
- 1) 매출 3차 분류 용어를 `분쇄품/미세척분쇄품/압출펠렛`으로 통일했다.
- 2) 분류 규격화 타이밍을 문서 단계로 쪼개어 운영 순서를 고정했다.
- 3) 차량번호/거래처/품목/날짜 포함 필수 저장 항목을 명시해 조회 가능성을 보장했다.

## 입문자 설명 3줄
- 1) 같은 뜻의 용어를 하나로 통일해야 나중에 검색/집계가 정확해진다.
- 2) “언제 규칙을 고정할지”를 정해두면 중간에 기준이 흔들리지 않는다.
- 3) 조회에 필요한 값(차량, 거래처, 품목, 날짜)을 처음부터 저장해야 나중에 찾을 수 있다.

## 주의 사항
- AI가 용어 통일 시 과거 문서/코드의 옛 라벨을 일부 놓칠 수 있어 추후 일괄 검색 점검이 필요하다.
- 필수 저장값을 문서에만 두고 실제 파서 출력에 반영하지 않으면 운영 데이터가 다시 불완전해질 수 있다.

## 향후 과정
- 다음 단계에서 parser/adaptor 출력 스키마를 필수 저장값 기준으로 맞춰야 문서-구현이 일치한다.
- 용어 통일 이후 조회 화면 필터 라벨도 동일 용어로 동기화해야 사용자 혼선을 막을 수 있다.
