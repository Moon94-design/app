# src2 레거시 의존 체크리스트 문서화

> 작성일: 2026-02-11
> 주제: src2에서 아직 @legacy를 참조하는 미이관 항목 목록 정리

---

## 변경 요약
- 현재 `src2/app/**`의 `@legacy` 참조를 전수 스캔해, 미이관 항목을 체크리스트 문서로 고정했다.
- 라우트 로더 기준 미이관 페이지와 엑셀 허브 브리지 의존을 분리해 정리했다.

## 추가 문서
- `company-docs/src2/docs/reference/src2-legacy-import-checklist.md` (신규)
  - A. 라우트 로더 기준 미이관 페이지
  - B. 엑셀 허브의 레거시 브리지 의존
  - C. 전역 스타일 의존(정책상 유지 가능 항목)
  - D. 우선순위 제안, E. 재점검 명령

## 스캔 기준
- 명령: `rg -n "@legacy/" company-docs/src2/app`
- 기준 시점: 문서 작성 시점 워크스페이스 상태

다음 질문: 체크리스트 기준으로 다음은 `register/daily` 4개부터 이관 시작할까?

## 핵심 로직 3줄
- 1) `src2/app`에서 `@legacy` import를 정규식으로 전수 검색했다.
- 2) 결과를 라우트 미이관/엑셀 브리지/정책 유지 항목으로 분류했다.
- 3) 바로 실행 가능한 우선순위와 재점검 명령까지 문서에 고정했다.

## 입문자 설명 3줄
- 1) 지금 남은 레거시 의존을 먼저 목록으로 만들면 “무엇부터 옮길지”가 선명해진다.
- 2) 페이지 미이관과 엑셀 브리지 의존은 성격이 달라서 분리해서 관리해야 한다.
- 3) 같은 검색 명령으로 반복 점검하면 누락 없이 진행 상황을 추적할 수 있다.

## 주의 사항
- AI가 검색 결과를 문서로 옮길 때 경로/레이블 매핑을 잘못 적을 가능성이 있어, 라우트 경로는 실제 `navConfig.ts`와 대조 검증이 필요하다.
- 패턴 반복 문서화 특성상 새로 추가된 파일이 즉시 반영되지 않을 수 있어, 작업 시작 전 재스캔을 반드시 수행해야 한다.

## 향후 과정
- 다음 이관 작업에서 체크박스를 문서 기준으로 갱신해 “완료/미완료”를 단일 SSOT로 유지한다.
- 엑셀 브리지 제거 작업을 시작하면 이 문서 B 섹션 항목이 연쇄적으로 바뀌므로, 관련 결과파일과 함께 동시 업데이트해야 한다.
