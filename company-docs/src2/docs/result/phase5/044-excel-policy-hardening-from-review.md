## 핵심 로직 3줄
- 1) `site`는 추론보다 업로드 필수 입력을 우선으로 고정했다.
- 2) KORA `slipNo` 공란 행은 자동 중복 확정 금지, reviewQueue로 보낸다.
- 3) 자동화 성과 퍼센트 대신 confidence 등급으로 의사결정을 표준화했다.

## 입문자 설명 3줄
- 1) 지점(site)이 틀리면 데이터가 섞이므로 사람이 먼저 지점을 고르게 한다.
- 2) 핵심 번호가 비어 있는 행은 자동으로 합치지 않고 사람이 확인한다.
- 3) “몇 % 자동” 같은 표현보다, 신뢰도 등급으로 처리하면 실수 관리가 쉽다.

## 주의 사항
- AI가 정책 문구를 빨리 맞추는 과정에서 실제 UI 입력 흐름(필수값 강제) 반영을 놓칠 수 있다.
- 규칙이 문서에만 있고 코드에 반영되지 않으면 운영 시점에 다시 혼선이 생길 수 있다.

## 향후 과정
- 다음 작업에서 업로드 UI에 `site 필수 선택`을 실제로 강제해야 정책-구현 불일치를 막을 수 있다.
- Extra/KORA 파서 적용 시 본 정책의 예외 규칙이 누락되면 연결된 reviewQueue 흐름이 깨질 수 있으니 동시 점검이 필요하다.
