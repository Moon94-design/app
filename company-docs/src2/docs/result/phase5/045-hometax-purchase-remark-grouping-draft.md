# Hometax 매입 비고/품목명 묶음 초안

> 작성일: 2026-02-11
> 주제: 매입 전자세금계산서 텍스트를 전수 추출해 유사 표현 통합 분류 초안 작성

---

## 변경 요약
- Hometax 매입 파일에서 비고/품목명 값을 추출해 원문 목록을 정리했다.
- `운송비/운임/운송료` 계열을 하나의 통합 카테고리로 묶는 초안을 만들었다.
- 계좌/전화/차량번호/기간 텍스트는 분류보조로 분리하는 기준을 추가했다.

## 추가 문서
- `company-docs/src2/docs/reference/hometax-purchase-remark-grouping.md` (신규)
  - 비고 원문 29개 전수 목록
  - 품목명 원문 49개 전수 목록
  - 통합 카테고리 초안(A~E)
  - 원문 -> 카테고리 매핑 규칙 초안

## 게이트
- 문서 작업(빌드 미실행)

다음 질문: 이 초안에서 `운송비(통합)`에 포함할 경로/오더 문구를 더 좁혀서 확정할까?

## 핵심 로직 3줄
- 1) 매입 파일의 비고/품목명을 전수 추출해 원문 기준표를 만들었다.
- 2) `운송비/운임/운송료/경로문구`를 같은 운송 카테고리로 통합했다.
- 3) 계좌·전화·숫자 단독 값은 분류 근거가 아닌 보조 메모로 분리했다.

## 입문자 설명 3줄
- 1) 먼저 원문 목록을 다 뽑아야 규칙이 빠지지 않는다.
- 2) 비슷한 말은 하나의 큰 분류로 합쳐야 조회/집계가 쉬워진다.
- 3) 의미가 약한 값(계좌번호 등)은 분류용이 아니라 참고용으로만 쓰는 게 안전하다.

## 주의 사항
- AI가 패턴 매칭으로 빠르게 묶는 과정에서 문맥이 다른 항목(예: 경로 문구 vs 실제 운임)을 과묶음할 수 있다.
- 현재는 1개 샘플 파일 기준이라 월별/타 사이트 파일에서 새로운 변형 표현이 추가될 가능성이 높다.

## 향후 과정
- 다음 단계에서 사용자 검토로 카테고리 오분류를 정리한 뒤, 사전(rule dictionary)로 고정해야 한다.
- 이 분류 사전이 바뀌면 연결된 reviewQueue/집계 화면에 연쇄 영향이 있으니 버전 관리가 필요하다.
