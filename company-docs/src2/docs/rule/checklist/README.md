# CHECKLIST 카탈로그
작성일: 2026-02-13
목적: 작업 유형별 추가 체크리스트 원본 경로를 한 곳에서 찾기 쉽게 관리한다.

## 사용 순서
- 1) `src2/docs/rule/BASIC_EXECUTION_CHECKLIST.md` 먼저 작성
- 2) 현재 작업 유형에 맞는 아래 체크리스트를 추가 작성
- 3) 결과 문서는 `src2/docs/rule/checklist-result/` 하위에 저장
- 4) 공용화 가능한 수정사항이 나오면 해당 원본 체크리스트를 즉시 최신화하고, 반영 경로를 결과 문서에 기록

## 작업별 원본 체크리스트
- 페이지 리뉴얼: `src2/docs/rule/PAGE_RENEWAL_CHECKLIST.md`
- 배치 실행/검증: `src2/docs/rule/TASK_EXECUTION_CHECKLIST.md`
- 일일 페이지 리뉴얼 공용화: `src2/docs/rule/checklist/daily-renewal-commonization-checklist.md`
- (참고) 기존 유통 전용 파일: `src2/docs/rule/checklist/logistics-daily-renewal-commonization-checklist.md` (deprecated)
- 주의: 일일 공용 체크리스트에는 조회/서버이관/보안/권한 대비 항목까지 포함한다.

## 결과 문서 경로
- BASIC: `src2/docs/rule/checklist-result/basic/`
- 작업별: `src2/docs/rule/checklist-result/{task-name}/`
